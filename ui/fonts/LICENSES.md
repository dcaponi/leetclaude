# Bundled fonts

The page ships Latin subsets of these fonts (woff2, from Google Fonts) so it works offline.

| Font | Use | License |
|---|---|---|
| Atkinson Hyperlegible Next | body text | SIL Open Font License 1.1 (`atkinsonhyperlegiblenext-OFL.txt`) |
| Atkinson Hyperlegible Mono | code | SIL Open Font License 1.1 (`atkinsonhyperlegiblemono-OFL.txt`) |
| Anton | display headings | SIL Open Font License 1.1 (`anton-OFL.txt`) |
| Permanent Marker | marker scrawls in the wordmark | Apache License 2.0 (`permanentmarker-LICENSE.txt`) |

Atkinson Hyperlegible was designed by the Braille Institute for low-vision readers, which is why the body and code text use it.
